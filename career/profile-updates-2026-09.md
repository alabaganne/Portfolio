### MenuMate case study

Title: MenuMate: Digital Menus and Ordering for Restaurants

Role: Founder, Designer, and Full-Stack Developer

Overview:

I designed, built, and launched MenuMate, a SaaS platform that lets restaurants manage digital menus, generate QR codes, and accept real-time orders from one dashboard.

The problem:

The product brings menu publishing and order management into the same workflow. Restaurants need a customer-facing menu that works on a phone and an admin interface for keeping menu content current and managing incoming orders.

What I built:

• Responsive digital menus with multilingual support.
• QR-code generation for access to restaurant menus.
• An admin dashboard for menu and order management.
• Real-time ordering backed by Supabase and PostgreSQL.
• A Next.js and React frontend styled with Tailwind CSS.

A key implementation choice:

The public menu and management dashboard serve different users. Customers get a browsing and ordering interface, while restaurant staff get controls for maintaining menus and managing orders.

Result:

A live SaaS product connecting menu publishing, QR access, and ordering. The public site demonstrates the product, and the screenshots show the interface I designed and built.

Stack: Next.js, React, Tailwind CSS, Supabase, PostgreSQL

### Martinez Auto Detail case study

Title: Martinez Auto Detail: Custom Booking and Payment Integration

Role: Freelance Full-Stack Developer

Overview:

I built a custom booking system for Martinez Auto Detail. Customers can select a service, see pricing, choose an appointment time, and provide card details through the Square integration. The owner manages the workflow from a dashboard.

The problem:

The booking flow needed to connect the business's service selection and pricing with scheduling and card storage for no-show protection. These steps had to work together in a responsive customer experience.

What I built:

• Service selection with dynamic pricing.
• Date and time selection for appointments.
• Square integration for card storage and no-show protection.
• An owner dashboard.
• A responsive Next.js and React interface with Tailwind CSS.

A key implementation choice:

The card-storage flow uses Square's API. This connects the custom booking interface to the payment provider's card-storage capability, alongside the business's service and scheduling workflow.

Result:

A live client booking system that combines service selection, pricing, scheduling, and the payment integration in one flow.

Stack: Next.js, React, Tailwind CSS, Square API
