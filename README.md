# Ala Baganne: Portfolio

My portfolio website and the career and freelance files behind it.

**Live website:** [alabaganne.com](https://alabaganne.com)

## Folders

- `website/` - the portfolio website (Next.js). See [its README](website/README.md).
- `career/` - resumes, cover letters, job search notes, and certifications
- `services/` - freelance service offers and their marketplace images. Start with [the service list](services/README.md).
- `brand-assets/` - profile copy and cover images
- `business-ideas/` - product ideas, gig ideas, and analysis
- `media/` - project screenshots, mockups, and social media posts
- `resources/` - live demo list and other notes

## Run the website

```sh
cd website
npm install
npm run dev
```

Open http://localhost:3000.
